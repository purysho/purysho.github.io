FIELD NOTE / 003 Maintenance is easier when change is visible.

These tools treat the filesystem like terrain: compare layers, identify redundancy, and measure where space is accumulating before changing anything.

01RIFTDIFFERENCE SURVEY

Rift

See exactly what changed.

Compare two folder trees without modifying either one. Rift classifies files as added, removed, changed, or unchanged and uses SHA-256 when content needs verification.

  • Read-only directory comparison
  • SHA-256 content checks
  • Likely rename detection
  • JSON and CSV export

02CULLREDUNDANCY REVIEW

Cull

Find duplicates. Decide safely.

Cull groups exact duplicates by content, surfaces near-name candidates for review, calculates reclaimable space, and uses reversible quarantine instead of permanent deletion.

  • Exact duplicate grouping
  • Near-name review candidates
  • Reclaimable-space estimates
  • Reversible quarantine workflow

03QUARRYSPACE ANALYSIS

Quarry

Find what is consuming the drive.

Quarry scans a directory and turns storage into a readable survey: biggest files, top-level usage, extension totals, age buckets, and a visual treemap of what is taking up space.

  • Largest-file analysis
  • Folder, extension and age totals
  • Treemap-style visualization
  • JSON export
