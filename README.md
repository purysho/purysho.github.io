# Purysho

Source for [purysho.github.io](https://purysho.github.io/) — the public portfolio and project index for Purysho.

The site groups projects into four collections:

- **Understand** — inspection, search, storage, and evidence systems.
- **Operate** — tools for requests, workflows, processes, and runtime control.
- **Maintain** — comparison, cleanup, and disk analysis.
- **Wander** — exploratory tools for repositories, open questions, and ideas.

The site is intentionally lightweight: static HTML/CSS/JS, no build service required for the published pages, and GitHub Pages handles deployment from this repository.
