Repository 01✦ Discover

GitHub Treasure Hunt

A calm, static discovery engine for open-source gems. Search a keyword, browse a topic, narrow to hidden gems, or roll the dice for a serendipitous repository — straight from GitHub's public search API.

  • → Search by idea — climate, accessibility, terminal
  • → Explore by topic: AI, design, security, education, dev tools
  • → Filter by star count to find genuinely hidden gems
  • → "Surprise Me" hands you one hand-picked repo at a time
  • → No AI agents, no accounts, no analytics — arrive, discover, leave

Repository 02✦ Wonder

The Open Questions Atlas

A calm, searchable map of the questions humanity has not answered yet. It turns open problems into a place to wander — where each question is the hero, with just enough context and a direct path into the source.

  • → Atlas regions — browse the unknown by field, cosmology to medicine
  • → Curated trails through origins, time, or the mind
  • → A "question of the week" to begin with one open problem
  • → Related questions keep a line of inquiry going
  • → Every entry is sourced and traceable — honesty over volume

Repository 03✦ Remember

Lodestar

A quiet, personal night sky for the things that struck you. Add a repository, question, link or thought; place it among your stars; then draw and name the constellations that matter to you. The whole sky lives in your browser.

  • → Add stars with a title, note, tags and an optional link
  • → Drag to place — normalized positions survive reloads and screens
  • → Connect stars with a keyboard-friendly click-click flow
  • → Faint suggestions appear when two stars share a tag
  • → Export, import or share your whole sky as portable JSON

Shared principles

Small tools, held to one standard.

Different subjects, one temperament. Every project in the trilogy is built the same disciplined way.

🜛

Static & client-side

Vite builds, deployed on GitHub Pages. Nothing to run, nothing to host, nothing to break.

◯

No accounts, no tracking

No sign-ups, no analytics, no secrets. Your data — when there is any — stays in your own browser.

✶

Sourced & honest

A smaller true atlas beats a padded one. Every question is traceable to a real primary source.

⌨

Keyboard-accessible

Visible focus states everywhere — search, filters, links and star-drawing all work without a mouse.

◐

Deliberately simple

One centred panel, one accent colour, one clear job. Arrive, do the thing, leave lighter.

✦

Built in public

Open issues, good-first-issue labels, MIT licences. The whole trilogy is out in the open.

Made by purysho. A set of small, calm tools for curious people — quietly shipped, openly sourced, and connected by a single throughline from discovery to memory.
